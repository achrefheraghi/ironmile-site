Many Confluence sites use Better Code Macro today. Code Block+ includes an admin importer that tells you, space by space, how many of those code blocks it recognises before you change anything.

## What the importer does today

The importer is scan-only:

1. A Confluence admin opens **Confluence settings**, then **Code Block+ import**.
2. Pick a space and run a **dry run**.
3. The report shows the pages scanned, the blocks that can be converted, the blocks that would be skipped (with the reason for each) and the macro keys it matched.

The dry run reads pages and writes nothing. Your pages stay exactly as they are.

## Converting blocks

Converting the matched blocks is coming in an update. No date is promised. Until then, the dry-run report tells you how large the migration for each space will be.

## Questions

Email **support@ironmile.dev** with your site name and the space you scanned. A copy of the dry-run report helps.
